# Custom badge icons (optional)

By default, chat badges (mod, VIP, OG, etc.) use simple built-in icons.

To use Kick's actual badge icons instead, save them here as PNGs named
exactly:

    broadcaster.png
    moderator.png
    vip.png
    og.png
    founder.png
    subscriber.png
    verified.png

Recommended size: 24x24 or larger, transparent background. Any badge file
you don't add just keeps using the built-in icon — no need to supply all
seven.

You can save these yourself from kick.com (e.g. right-click -> Save Image
on a badge next to a chatter's name, or grab them from your browser's dev
tools Network tab while chat is open). They aren't redistributed with this
app since they're Kick's own artwork.
